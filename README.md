# 🚀 First Portfolio

This project will be a website that will showcase my skills and bring a creative flair to designing websites.
The inspiration for this project is to create an interactive, Windows-like desktop that makes playing with the website engaging. It serves as a way to practice basic HTML, CSS, and JS skills while also developing a portfolio to highlight everything that a resume may not encapsulate.
The features included are as follows:
  - Interactive UI 
  - About Me
  - Links
  - Experience
  - Projects
